# GameHub Comprehensive Data Dictionary

**Author:** Nikhil  
**Status:** Unified Database Dictionary (Post-Migration 004)

---

## 1. `games`
Stores the library of gaming titles available at the cafe along with dense AI search embeddings.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `game_id` | SERIAL | No | PRIMARY KEY | Unique surrogate identifier for each game title. |
| `title` | VARCHAR(100) | No | NOT NULL | Official name of the game title. |
| `category_id` | INTEGER | Yes | FK -> `game_categories(category_id)` ON DELETE SET NULL | Genre classification key. |
| `description` | TEXT | Yes | None | Full description used for semantic vector extraction. |
| `search_embedding` | vector(384) | Yes | HNSW Cosine Index | 384-dimensional dense vector generated by `all-MiniLM-L6-v2`. |
| `embedding_model` | TEXT | Yes | None | Model name string used to produce embedding. |
| `embedding_updated_at` | TIMESTAMPTZ | Yes | None | Timestamp when embedding was generated or refreshed. |
| `is_active` | BOOLEAN | No | DEFAULT TRUE | Soft-archival flag. Inactive games are hidden from default catalogue views. |

---

## 2. `game_categories`
Lookup relation for game genre classifications.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `category_id` | SERIAL | No | PRIMARY KEY | Unique identifier for category. |
| `category_name` | VARCHAR(50) | No | UNIQUE, NOT NULL | Distinct genre label (e.g. FPS, RPG, Battle Royale). |

---

## 3. `tournaments`
Stores scheduled competitive tournaments and events.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `tournament_id` | SERIAL | No | PRIMARY KEY | Unique tournament identifier. |
| `name` | VARCHAR(100) | No | NOT NULL | Tournament event name. |
| `game_id` | INTEGER | No | FK -> `games(game_id)` | Featured game for tournament. |
| `prize_pool` | DECIMAL(10,2) | Yes | CHECK (prize_pool >= 0) | Prize money allocation in INR. |
| `start_date` | DATE | No | NOT NULL | Scheduled start date for event. |
| `status` | TEXT | No | DEFAULT 'open', CHECK in ('draft','open','closed','completed','cancelled') | Current tournament lifecycle stage. |
| `max_participants` | INTEGER | Yes | CHECK (max_participants > 0) | Maximum participant capacity limit. |
| `registration_deadline` | TIMESTAMPTZ | Yes | None | Cutoff timestamp for registrations and cancellations. |
| `description` | TEXT | Yes | None | Tournament rules and event details. |

---

## 4. `tournament_registrations`
Associative junction table resolving M:N relationship between Tournaments and Customers.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `tournament_id` | INTEGER | No | PK, FK -> `tournaments(tournament_id)` ON DELETE RESTRICT | Enrolled tournament. |
| `customer_id` | INTEGER | No | PK, FK -> `customers(customer_id)` ON DELETE RESTRICT | Registered participant. |
| `registration_date` | TIMESTAMP | No | DEFAULT CURRENT_TIMESTAMP | Registration confirmation timestamp. |

---

## 5. `session_games`
Associative junction table resolving M:N relationship between Gaming Sessions and Games played.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `session_id` | INTEGER | No | PK, FK -> `gaming_sessions(session_id)` ON DELETE RESTRICT | Active or completed gaming session. |
| `game_id` | INTEGER | No | PK, FK -> `games(game_id)` ON DELETE RESTRICT | Game played during session. |
| `play_duration_minutes` | INTEGER | Yes | Legacy baseline column | Duration in minutes. |
| `duration_minutes` | INTEGER | Yes | CHECK (duration_minutes >= 0) | Recorded playtime in minutes. |
| `added_at` | TIMESTAMP | No | DEFAULT CURRENT_TIMESTAMP | Timestamp when game was attached to session. |

---

## 6. `gaming_pcs`
Hardware inventory tracking PC stations and real-time operational status.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `pc_id` | SERIAL | No | PRIMARY KEY | Unique identifier for gaming PC station. |
| `pc_name` | VARCHAR(50) | No | UNIQUE, NOT NULL | Machine identifier (e.g. Alienware-01, ROG-01). |
| `status` | VARCHAR(20) | No | DEFAULT 'available', CHECK in ('available','occupied','maintenance') | Real-time station availability state. |
| `hourly_rate` | DECIMAL(5,2) | No | NOT NULL | Standard hourly billing rate in INR. |

---

## 7. `gaming_sessions`
Core transactional records of customer PC sessions, duration, and calculated billing.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `session_id` | SERIAL | No | PRIMARY KEY | Unique session identifier. |
| `customer_id` | INTEGER | No | FK -> `customers(customer_id)` ON DELETE RESTRICT | Playing customer. |
| `pc_id` | INTEGER | No | FK -> `gaming_pcs(pc_id)` ON DELETE RESTRICT | Assigned PC station. |
| `start_time` | TIMESTAMP | No | DEFAULT CURRENT_TIMESTAMP | Session initiation timestamp (UTC). |
| `end_time` | TIMESTAMP | Yes | None | Session termination timestamp (UTC). |
| `expected_end_time` | TIMESTAMP | Yes | None | Expected end time for reservation conflict checking. |
| `reservation_id` | INTEGER | Yes | FK -> `reservations(reservation_id)` | Linked reservation if initiated from a booking. |
| `hourly_rate_snapshot`| NUMERIC(8,2) | Yes | None | Rate locked at session initiation to preserve billing accuracy. |
| `total_cost` | DECIMAL(7,2) | Yes | Calculated via trigger | Final session cost calculated from rate snapshot. |

---

## 8. `reservations`
Customer PC advance bookings with exclusion constraints preventing overlaps.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `reservation_id` | SERIAL | No | PRIMARY KEY | Unique reservation identifier. |
| `customer_id` | INTEGER | No | FK -> `customers(customer_id)` ON DELETE RESTRICT | Booking customer. |
| `pc_id` | INTEGER | No | FK -> `gaming_pcs(pc_id)` ON DELETE RESTRICT | Reserved PC station. |
| `start_time` | TIMESTAMP | No | NOT NULL | Booking start time. |
| `end_time` | TIMESTAMP | No | NOT NULL, CHECK (end_time > start_time) | Booking end time. |
| `status` | TEXT | No | DEFAULT 'confirmed', CHECK in ('confirmed','cancelled','completed') | Reservation status. |
| `notes` | TEXT | Yes | None | Special customer requests or notes. |
| `created_by_staff_id` | INTEGER | Yes | FK -> `staff(staff_id)` | Staff member who created or assisted booking. |
| `created_at` | TIMESTAMP | No | DEFAULT CURRENT_TIMESTAMP | Booking record creation timestamp. |

---

## 9. `maintenance_records`
Hardware defect and maintenance tracking logs.

| Column Name | Data Type | Nullable | Constraints / Default | Description |
|---|---|:---:|---|---|
| `maintenance_id` | BIGSERIAL | No | PRIMARY KEY | Surrogate primary key. |
| `pc_id` | INTEGER | No | FK -> `gaming_pcs(pc_id)` ON DELETE RESTRICT | Target PC station. |
| `maintenance_date` | DATE | No | UNIQUE with `pc_id` | Date of recorded maintenance issue. |
| `issue_description` | TEXT | No | NOT NULL | Description of malfunction or repair task. |
| `resolved` | BOOLEAN | No | DEFAULT FALSE | Resolution indicator. |
| `resolved_at` | TIMESTAMP | Yes | Timestamped via trigger | Timestamp when resolved was marked true. |

---

## 10. `customers` & `staff`
Store patron profiles and staff operational accounts.

| Table | Primary Key | Key Attributes | Description |
|---|---|---|---|
| `customers` | `customer_id SERIAL` | `name`, `email UNIQUE`, `phone`, `join_date`, `updated_at` | Customer contact and registration details. |
| `staff` | `staff_id SERIAL` | `name`, `role ('admin','manager','attendant')`, `shift` | Staff employee records and shift assignments. |

---

## 11. Commerce Tables
Store membership tiers, customer subscriptions, snack inventory, orders, and payments.

| Table | Primary Key | Key Attributes | Constraints & Triggers |
|---|---|---|---|
| `membership_plans` | `plan_id BIGSERIAL` | `name UNIQUE`, `price`, `duration_days`, `discount_percent` | Predefined membership tier configurations. |
| `customer_memberships` | `membership_id BIGSERIAL` | `customer_id`, `plan_id`, `start_at`, `end_at`, `price_paid`, `status` | Snapshot trigger sets price and validity dates. |
| `snack_items` | `snack_id BIGSERIAL` | `name UNIQUE`, `category`, `unit_price`, `stock_quantity`, `is_active` | Cafe snack inventory catalogue. |
| `orders` | `order_id BIGSERIAL` | `customer_id`, `status`, `subtotal`, `discount_amount`, `total_amount` | Trigger automatically applies active member discount. |
| `order_items` | `order_item_id BIGSERIAL` | `order_id`, `snack_id`, `quantity`, `unit_price_at_purchase`, `line_total` | Snapshot item prices and line totals at purchase. |
| `payments` | `payment_id BIGSERIAL` | `order_id UNIQUE`, `amount`, `method`, `status ('paid',...)` | Settlement records; triggers inventory deduction upon payment. |
